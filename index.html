Phase 1 — The Problem Statement

Traveling Users Stranded by Repetitive IT Tickets

Users across business units were raising tickets for the same basic operating system glitches, losing valuable hours waiting for IT support—especially while traveling across client sites, hotels, and airports.

Traveling Staff Stranded Across Time Zones

Consultants and mobile users traveling to client offices or hotels faced recurring network adapter hangs, stale DNS records, and captive portal drops. With IT operating across specific support hours, users lost hours waiting for remote assistance before important client meetings.

Critical Billable Hours Wasted in Transit

High Ticket Queue for Basic, Identical Glitches

The IT Service Desk was overwhelmed with high-volume repetitive tickets: corrupted Windows Update download caches, hung print spoolers, unresponsive network stacks, and corrupted Teams/Outlook caches that required the exact same basic troubleshooting commands every single time.

30–45 Mins Average Ticket Wait Time

Disproportionate Time Lost for 2-Minute Fixes

While executing a DNS flush or restarting a frozen Windows service takes under 2 minutes of actual command execution, the end-to-end user turnaround took up to 45 minutes due to ticket logging, queuing, remote desktop connection, and technician availability.

Long Resolution Latency for Minor Issues

Lack of Safe Self-Service Tooling for Non-Tech Users

End users could not safely resolve issues themselves. Running manual commands like netsh int ip reset or clearing SoftwareDistribution manually required command-line knowledge and elevated privileges, posing risks of accidental misconfiguration.

Zero Safe One-Click Options Available

Phase 2 — Engineering & Architecture

Building the <100 KB Self-Service Batch Utility

Architected a standalone, menu-driven Windows Batch utility designed specifically for non-technical employees and internal L1 technicians, packaging the top 8 diagnostic and recovery procedures into instant one-click actions.

1 Complete Network Reset

Resets the TCP/IP stack and Winsock catalog back to clean default states after hotel or captive Wi-Fi lockups.

netsh int ip reset & winsock reset
2 DNS Flush & IP Renewal

Purges corrupted local DNS resolver cache, releases expired DHCP addresses, and queries a fresh IP lease.

ipconfig /flushdns /renew
3 Windows Update Repair

Stops wuauserv & BITS, purges corrupted SoftwareDistribution download files, and cleanly restarts daemons.

net stop wuauserv & del cache
4 Enterprise App Cache Flush

Safely purges corrupted local app caches for Microsoft Teams, Outlook, and web browsers to fix launch crashes.

rd /s /q %localappdata%\Microsoft\Teams
5 Print Spooler Reset

Restarts hung spoolsv service and clears jammed print jobs locked in the Windows print queue directory.

net stop spooler & del *.shd
6 System File Integrity Scan

Initiates automated, non-destructive System File Checker to detect and restore corrupted Windows OS components.

sfc /scannow
7 Temp Files & Disk Cleanup

Cleans locked user temp folders and orphaned installation buffers without deleting personal files.

del /f /s /q %temp%\*
8 Diagnostic System Summary

Generates an instant, exportable text report with active IP status, gateway connectivity, and uptime for IT escalations.

netsh & systeminfo > report.txt
