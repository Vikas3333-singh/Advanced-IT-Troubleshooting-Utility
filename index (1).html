01 — Context
The Problem

Manual maintenance — every time, every endpoint

L1/L2 support engineers at Femmella Fashions were executing the same maintenance tasks manually on each endpoint — no consistency, no speed, and zero ability to automate or scale.

Temp cleanup, disk repair, driver updates, Office repair — done one by one manually
No standardisation across Windows and macOS endpoints in the fleet
No CLI/silent deployment support for Intune or SCCM rollout
The Solution

Full maintenance lifecycle — one command

Advanced IT Troubleshooting Utility standardises endpoint maintenance across both platforms. Engineers run one command instead of a manual checklist. Silent CLI mode enables zero-interaction deployment via Intune/SCCM.

mac_maintenance.sh — sudo

02 — Scripts

Two platforms. One toolkit.

Windows
windows_maintenance_final.bat
Windows 10 / 11 · Run as Administrator
  • Natural language issue routing — user types problem in plain English, script routes to the right menu automatically
  • 15 CLI arguments for silent automated execution (temp, sfc, dism, drivers, office, diskcleanup…)
  • Disables 20+ non-essential Windows services for performance gains
  • Intune/SCCM-ready: silent mode with full CLI argument support
  • Optional maintenance_config.ini for custom deployment settings
macOS
maintenance.sh
v2.1 · macOS Ventura+ · set -Eeuo pipefail
  • Atomic process locking — prevents concurrent runs, stores PID for diagnostics
  • --dry-run mode previews every destructive action — zero changes made
  • Log rotation at 10MB, keeps last 5 rotated logs, writes to Console.app via logger
  • Disk space pre-check before backup; aborts if insufficient space detected
  • JSON system reports retained 90 days in /Library/Application Support/Femella/
03 — Capabilities

What the Utility Automates

Performance Optimisation
Temp cleanup, disk defrag, service disabling, app cache clearing (Slack, Chrome, Teams, Discord).
System Health Checks
SFC, DISM, diskutil verifyVolume, memory pressure reporting, hardware diagnostics.
Driver & Software Updates
Windows driver scan via pnputil, Homebrew update/upgrade/cleanup, Windows Update automation.
App Repair
Microsoft Office repair, Microsoft Store reset, app cache clearing for productivity apps.
Battery & Power
Battery health report with cycle count and wear level; High Performance power plan; macOS system_profiler parsing.
Backup & Reporting
rsync backup with pre-flight disk space check; JSON system reports; rolling log rotation; SIEM-ready event logging.
